# 변경사항 요약서 (v4) — 변경 전 → 변경 후

기존 `corona_reco`/`CoronaReco.exe` 구조를 **최대한 유지**하면서 수정 지시서 v4(§1~§6)를
반영했다. 모듈 단위로 나눠 구현하고 각 단계 커밋으로 보존했다.

---

## §1. 등급 체계: S/A/B/C/D → 즉시관리 / 당월관리 / 보류

| 항목 | 변경 전(v3) | 변경 후(v4) |
|---|---|---|
| 등급 | S·A·B·C·D 5단계 | **즉시관리 / 당월관리 / 보류 3단계** |
| 부담당자 상한 | S≤20, A≤100 | **즉시+당월 기본 150, 고스코어 시 200 초과편입, 200 하드캡** |
| 최소보장 | 부담당자별 20건 강제 편입(참고대상) | **삭제** — 억지로 채우지 않음 |
| 즉시/당월 분할 | (해당 없음) | **점수분포 최대갭(데이터 주도), 실패 시 상위 30% 분위수** |
| 초과편입 임계 | (해당 없음) | **정상편입(≤150) 점수 중앙값 이상**(절대하한 45 병행) |
| 추천여부 | S/A/B True, 최소보장 편입 포함 | **즉시·당월(초과편입 포함)만 True, 보류=False** |
| 원등급/최종등급 | S상한 전/후 | **모델 판정(원등급) / 정원 적용(최종등급) 분리** |
| 동점 처리 | 점수→차주합산잔액→… | **동일(점수→차주합산잔액→1M→3M→최근입금일→안정키)** 계승·확장 |

구현: `grading.assign_original_tier` / `apply_assignee_caps` / `apply_recommendation_flags`.
컬럼: 원등급·최종등급·즉시관리후보여부·정원초과편입여부·상한적용여부·상한전/후_담당자내순위·
동일차주계좌합산원금잔액·상한하향사유·추천순위_차주기준·추천순위_계좌기준.

## §2. 소액 과다추천 교정

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 소액 필터 | 계좌 현재원금 100만원 이하 제외 | **동일차주 계좌합산 원금잔액 500만원 이하 차주 추천 제외**(제외채권 시트) |
| burden_score | ≤100만 90 / ≤300만 100(소액 정점) / … / >5,000만 25 | **≤500만 55 / 500만~1,000만 88 / 1,000만~3,000만 100(정점) / …~1억 70 / >1억 55** |

구현: `grading.assign_original_tier`(소액제외여부), `scoring.compute_burden_score`.

## §3. 랜덤박스(앱 표시 전용)

- 신규: 합산 **1,000만원 이상** 접촉가능 차주 → 점수순 상위 **20명** 중 **무작위 5명**.
- 매 클릭 새 시드 → 다른 5명. 표시: 고객번호·부담당자·합산잔액 3개.
- 구현: `grading.randombox_pick`, UI 🎲 버튼 + '다시 뽑기'.

## §5. 누적 학습 영속화 + 학습기억 무결성 가드

- 초기 학습데이터를 `training_rows`에 1회 보존 → 매월 **누적 재학습**(스냅샷+피드백 라벨).
- `store_state`: store_id(UUID)·스키마버전·최초/마지막학습일·반영 피드백 월수·누적표본/positive·
  dirty·체크섬. 앱 시작 **3색 무결성 배너(🟢/🟡/🔴)**.
- 🔴/🟡 최초 실행 시 **초기화 방지 모달**(복구 시도 / 명시동의 후 새로 시작).
- 자동 백업(`data/backup/` 10개 회전) + `store_audit.log` + dirty 플래그(비정상 종료 감지).

## §0 계승(불변)

시간축 누수 방지(t0 이전 피처 · 1M/3M 라벨), Stage1×Stage2 예상회수(=P×E, fallback),
차주 통합(0.7max+0.3mean), 시간/그룹 분할 검증(Lift@5/10%·Precision@50/100·기준선),
선택편향 진단, 실무 엑셀(표지/팀리스트/요약/제외/법조치/관리현황/피드백),
팀 roster, xls/xlsx 안정화, 오류/추천사유, 주민번호 미저장·성별 미반영.
