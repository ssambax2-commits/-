# 사양 라이브러리 (docs/spec)

이 폴더는 `corona_reco` 앱을 **재생성·검증·인수인계**할 수 있는 문서 라이브러리다.
코드와 함께 버전 관리되므로 항상 현재(v4) 구현과 일치한다.

| 파일 | 용도 | 언제 쓰나 |
|---|---|---|
| **BUILD_PROMPT.md** | 자기완결형 **빌드 프롬프트**(재생성 지시) | 새 세션/새 환경에서 앱을 처음부터 다시 만들 때 붙여넣기 |
| **SPECIFICATION.md** | 정식 **사양서**(값·계약·알고리즘 단일 진실 원천) | 규칙·상수·데이터 계약을 정확히 확인/변경할 때 |
| `../변경사항_요약서_v4.md` | v3→v4 변경 전/후 | 무엇이 바뀌었는지 |
| `../알고리즘_검토_의견서.md` | 알고리즘 선택 근거·후보 비교·fallback | 왜 이 구조인지, 담당자 설득/고도화 |

## 사용법
- **그대로 다시 만들기**: `BUILD_PROMPT.md` 전체를 새 Claude Code 세션에 입력.
- **규칙 하나만 바꾸기**: `SPECIFICATION.md`에서 해당 상수를 찾아 `corona_reco/config.py`의
  같은 이름 상수를 수정 → `python -m pytest corona_reco/tests` → 재빌드.
- **인수인계**: 이 폴더 4개 문서 + README(루트) + 코드면 충분.

## 유지 원칙
규칙/상수를 코드에서 바꾸면 **반드시 SPECIFICATION.md의 해당 값과 §11 상수표도 함께 갱신**해
문서-코드 불일치를 막는다. 큰 등급/알고리즘 변경 시 BUILD_PROMPT.md의 §1~§5도 갱신한다.
