# 빌드 프롬프트 — 코로나채권/NPL·PL 우선관리 추천 데스크톱 앱 (재생성용)

> 이 문서 하나만 새 세션에 붙여넣으면 `corona_reco` 앱 전체를 처음부터 재생성할 수 있도록
> 작성한 **자기완결형 빌드 지시서**다. 현재(v4) 코드 상태를 반영한다.
> 정확한 상수·데이터 계약은 같은 폴더의 `SPECIFICATION.md`를 참조하라.

너는 이 프로젝트의 리드 엔지니어다. 아래 사양을 **전부** 구현해 회사 담당자가 매월 클릭해
쓰는 **Windows 실행파일(.exe)** 까지 나오게 만들어라. 코드는 생략 없이 실행 가능한 완성본으로
작성하고, 주석·UI·컬럼명은 한국어로 한다. 모듈 단위로 나눠 구현하고, 각 모듈 완료 시 커밋하라
(토큰 한도로 중간에 끊겨도 유실되지 않게).

## 0. 목적 · 실행환경 · 불변 원칙

**목적.** 채무조정이 폐지된 코로나채권 중, **접촉 시 1개월 내 자발 상환 가능성이 상대적으로
높은 차주**를 **부담당자별**로 추천한다. 법조치/강한 추심 추천 모델이 **아니다**(법조치는 참고
시트로만 분리).

**빌드 환경:** 인터넷 되는 노트북(pip 자유). **실행 환경:** 회사 내부망에서 .exe 실행 —
**실행(추론) 중 외부 API·CDN·인터넷 호출 절대 금지.** 외부 통계는 정적 상수로 내장. 필요한
라이브러리는 **exe에 번들**(PyInstaller).

**불변 원칙(반드시 유지):**
1. **시간축 누수 방지(최우선).** 기준일 t0 이전 정보만 피처로, t0 이후 1개월/3개월 입금
   여부·입금액을 라벨로. 익월 피드백 입금내역은 **다음 달 학습 라벨로만** 쓰고 당월 추천
   피처에 절대 섞지 않는다. 누수 blacklist(현재잔액/상태/회생/입금/피드백결과 등)를 빌드
   게이팅 테스트로 강제.
2. **Stage1 × Stage2.** 최종 예상회수액 = P(입금발생) × E(입금액|입금발생), 1개월·3개월
   분리. Stage2 불안정/positive 부족 시 세그먼트·전역 평균회수율 fallback + 보고서 표시.
3. **차주 단위 통합.** 고객번호+성명 기준 차주 통합점수 → 등급 결정 후 계좌에 동일 차주등급
   부여. 차주기준·계좌기준 추천순위 분리. 차주점수 = 0.70×max(계좌점수)+0.30×mean(계좌점수)
   − 다중계좌부담.
4. **검증.** 랜덤분할 금지 — 시간/고객번호 그룹분할. Lift@5/10%·Precision@50/100, 등급별
   실제입금률, 기준선(랜덤·잔액순) 대비. champion-challenger(지표 우세 시만 채택).
5. **선택편향 진단.** 추천/비추천·활동/비활동 입금률 구분 + 경고 플래그.
6. **주민등록번호 원본 미저장**(나이대 산출 후 폐기), **성별 점수 미반영**(공정성 진단만).
7. **팀 매핑(부담당자 roster 우선).** 2팀=김종일·서보문·정재민 / 1팀=민홍기·김승한·김영성·
   최병인·조은지 / 그 외=기타. 데이터 팀 컬럼과 충돌 시 roster가 이기고 불일치 건수 진단.
8. **모든 입력 row는 코로나채권으로 간주**(판별 컬럼/로직 만들지 말 것). **실제 관리담당자=
   부담당자**(공란이면 담당자 fallback, 없으면 "미지정").

## 1. 등급 체계 — 즉시관리 / 당월관리 / 보류 (3단계)

- **즉시관리**: 접촉 시 변제가능성이 가장 높은 최우선 차주.
- **당월관리**: 이번 달 안에 관리할 우선 차주.
- **보류**: 이번 달 추천 대상 아님 → 차월 재평가. **추천여부=False.**

**선정(부담당자별·차주 기준):**
1. **적격 필터**: 강제 제외(§3) 제거 + **동일차주 계좌합산 원금잔액 500만원 이하 차주 추천
   제외**(제외채권 시트).
2. 적격 차주를 부담당자별로 묶어 **변제가능성 점수**(차주 통합점수 = 규칙+Stage1 백분위+입금
   이력+상환부담 결합) 높은 순 정렬.
3. **부담당자별 상한:** 즉시+당월 **기본 150건**. **151~200건**은 원칙 보류이나 **점수가
   충분히 높으면(정상편입 ≤150 점수의 중앙값 이상, 절대하한 45 병행) 200건까지 "정원초과
   고스코어 편입"**(당월). **200 하드캡**, 초과분 전부 보류.
4. **즉시 vs 당월 경계**는 고정비율 금지 — **점수분포 최대갭(상위 5~50% 구간 탐색, 실패 시
   상위 30% 분위수)** 로 데이터 주도 결정.
5. **동점/경계 우선순위:** ①점수 ②동일차주 계좌합산 원금잔액 큰 순 ③1개월 예상회수액
   ④3개월 예상회수액 ⑤최근입금일 최신 ⑥고객번호/대출번호 안정정렬.
6. **원등급**(상한 전 모델 판정)과 **최종등급**(150/200 상한 후) **분리 표시**. 한 차주의
   모든 계좌에 동일 최종등급. 밀려 보류된 차주는 **상한하향사유** 기록.

필수 컬럼: 원등급·최종등급·즉시관리후보여부·**정원초과편입여부(151~200)**·상한적용여부·
상한전/후_담당자내순위·동일차주계좌합산원금잔액·상한하향사유·추천순위_차주기준·추천순위_계좌기준.
**최소건수 강제편입 없음.**

## 2. 소액 과다추천 교정
- **하드 필터**: 동일차주 계좌합산 원금잔액 **500만원 이하 차주 추천 제외**.
- **burden_score 곡선**: ≤500만 55 / 500만~1,000만 88 / 1,000만~3,000만 **100(정점)** /
  3,000만~5,000만 85 / 5,000만~1억 70 / >1억 55. (소액 정점 제거)
- **최근입금 의존도 완화**: 10만원 이하 단건 입금은 payment score ×0.6, 최근입금 단독요인
  과다(의존도≥0.6 & 다른 근거 약함)면 즉시→당월 강등. 진단 컬럼: 최근입금의존도·
  최근입금단독추천여부·최근입금가점제한여부.

## 3. 랜덤박스 (앱 표시 전용, 엑셀 출력 아님)

## 6. 강제 제외 규칙 + 차주 전파 (컴플라이언스)
계좌가 아래 중 하나면 제외하고 **제외사유 기록**: ①원장상태≠활동 ②채권상태(중)∈{사망·완제·
면책·시효·말소} ③채무부존재소송 ④회생∈{신용회복동의회신·인가결정·개시결정·신용회복지원확정·
신용회복지원신청·면책허가} ⑤(옵션 ON) 시효일자<기준일. `폐지_신복/폐지_회생/폐지_파산`은
절대 제외 금지(안내 가능). `부채증명원`은 무시(패널티·플래그 없음). **차주 전파**: 연락금지
(회생)·사망·면책은 동일 고객번호+성명 전 계좌 제외. 완제/시효/말소는 계좌 단위.

## 7. 점수 컴포넌트 & 최종식
- base(규칙점수) / paid_similarity(Stage1 1M 확률의 모집단 백분위) / payment_history(입금
  이력 우대) / burden(§2 곡선) 각 0~100.
- `pre = w.base*base + w.sim*sim + w.pay*pay + w.burden*burden` (기본 0.30/0.35/0.20/0.15).
- `final = clamp(pre×담보부NPL배수 − 민감패널티 + 외부prior + 피드백EB보정 + Stage2보정, 0,100)`.
- 담보부NPL(채권구분): 무입금 ×0.55·상한B / 입금有 ×0.70·상한A / 최근365일입금 ×0.80·S가능.
- 외부 prior: 나이대(±3)+개인사업자 보정[-8,+5]. 민감패널티: 민원 −25(중복1회)·법조치 −20.
- 차주 통합점수(=변제가능성 점수) = 0.70×max + 0.30×mean − 다중계좌부담(3건↑−3,5건↑−6).

**피드백 입력 파일(별도)**: 전체 채점 차주 수록(추천/비추천 모두 — 자연입금 관측). 사용자는
활동여부·실제입금여부·실제입금액·입금일자·비고만 채운다. 숨김 시트에 추천시점 피처벡터·대출번호·
모델버전.

## 10. 테스트 (pytest, 빌드 전 통과 필수)
반례(폐지 안내가능·회생 강제제외·사망/완제 제외·민원−25 1회·담보부NPL 배수/상한·개인사업자
보정·주민번호 처리·시효 제외·부채증명원 무시·차주 전파·팀 roster 우선·피드백 별칭) +
**누수 게이팅**(ML 피처 blacklist 0건, 실패 시 빌드 중단) + 3단계 등급/150·200 상한/동점

## 11. 빌드·배포 (.exe)
- **build.bat**: venv → pip install -r requirements.txt → pytest(실패 시 중단) →
  PyInstaller `--onefile --windowed` → dist/exe. **build_offline.bat**(pip download 휠 기반).
- requirements: catboost·pandas·numpy·openpyxl·joblib·xlrd·customtkinter·darkdetect·
  pyinstaller·pytest. `.spec`에서 `collect_all('customtkinter'/'catboost'/…)`로 데이터 파일
  번들. **완성 exe는 실행 중 네트워크 불필요.**
- (선택) GitHub Actions `windows-latest`에서 pytest→PyInstaller→Release 업로드로 인터넷
  브라우저 다운로드 제공.
