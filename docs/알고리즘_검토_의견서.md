# 알고리즘 검토 의견서 — 코로나채권/NPL·PL 우선관리 추천

## 1. 결론(요약)
사용자가 제시한 방향 — **기준일 t 설정 → t 이전 피처 / t 이후 1·3개월 입금 라벨 →
Stage1(입금확률)×Stage2(예상입금액) → 차주 통합 → 부담당자별 정원 배분 → 익월 피드백
캘리브레이션** — 은 이 업무에 **가장 합리적**이며, 현재 코드 구조가 이미 그 골격을 갖췄다.
전면 교체가 아니라 **하이브리드(모델점수 + 업무룰 + 팀별 calibration)** 를 유지·강화하는 것이
정답이다.

- **내부망**: CatBoost/GBM은 순수 파이썬 휠로 exe 번들 가능(외부호출 없음) → 적합.
- **소표본**: 코로나채권 positive가 매우 희소(≈0.9%)라 단일 딥러닝/복잡모델은 위험.

- **설득/설명**: 담당자에게는 "왜 이 차주인가"가 중요 → 룰 근거 + 추천사유 문장 병행.

## 3. 최종 권장 구조 (현 구조 유지)
1. **기준일 t0 = 평가기준일 − 3개월**(3M 관측창 확보). 피처는 t0 이전 **기표/매입 시점 고정값만**
   (현재잔액/상태/회생/입금/피드백결과는 blacklist 게이팅으로 원천 차단).
2. **Stage1**: 1개월/3개월 입금발생확률 — CatBoost 분류 **balanced bagging 앙상블**,
   positive<임계면 규칙·prior fallback.
3. **Stage2**: 입금 발생 시 예상입금액 — CatBoost 회귀(log 금액), 불안정/소표본이면
   **세그먼트(잔액구간×담보부NPL) 평균 → 전역 평균** fallback.
4. **최종 예상회수액 = P(입금) × E(입금액|입금)**, 1M·3M 분리. 모집단 평균확률을 학습 base
   rate에 맞추는 **전역 스케일링 캘리브레이션(순위 보존)**.
5. **변제가능성 점수** = 규칙점수(base) + Stage1 백분위(paid_similarity) + 입금이력 +
   상환부담(burden) 가중합 × 담보부NPL 배수 − 민감패널티 + 외부 prior + 피드백 EB보정.
   **최근입금 단독요인 과다는 즉시→당월 강등**(재추천기化 방지).
6. **차주 통합** = 0.70×max(계좌점수) + 0.30×mean(계좌점수) − 다중계좌부담.
   - *의견*: max 비중이 "최고 회수가능 계좌"를 대표하되 mean으로 안정화하는 절충안이 실무에
     타당. 대안으로 **잔액가중 평균**(Σ점수×잔액/Σ잔액)도 검토했으나, 소액 계좌가 점수를
     끌어내리는 부작용과 §2 소액 하한과의 충돌 우려로 **현행 0.7/0.3 유지 권장**. 데이터가
     쌓이면 익월 회수율로 max/mean 비중을 A/B 튜닝 가능.
7. **부담당자별 정원**: 즉시+당월 150(고스코어 200 초과편입, 200 하드캡). 즉시/당월 경계는
   점수분포 최대갭(데이터 주도).
8. **검증**: 랜덤분할 금지 — 시간/고객번호 그룹 분할. **Lift@5/10%·Precision@50/100**,
   등급별 실제입금률, 기준선(랜덤·잔액순 등) 대비. champion-challenger로 지표 우세 시만 채택.

## 4. 데이터 부족 시 fallback
- Stage1 positive<임계 → 규칙점수·외부 prior 위주(가중치 자동 재분배), 보고서에 폴백 표기.
- Stage2 금액표본 부족 → 세그먼트/전역 평균회수율.
- 모델 파일/DB 없음 → 규칙·prior 단독 + 무결성 배너 🔴.

## 5. 월별 피드백 누적 주의(선택편향)
- 추천채권 위주 활동 → 피드백이 추천군에 편중. **활동데이터 전체를 매월 넣어 전체 모수 기준
  라벨 생성**, 피드백 입금내역만으로 학습셋을 대체하지 말 것.
- 피드백파일에 **추천여부·원등급·최종등급·추천순위·담당자·활동여부** 저장 → 다음 학습에서
  추천/비추천·활동/비활동 입금률을 구분 진단, 편향 경고.
- **비추천 채권의 자연입금**도 라벨로 포함(편향 완화).

## 6. 향후 고도화
- 표본 축적 후: 캘리브레이션을 isotonic/Platt로 승격, Stage2를 분위수 회귀로 예측구간 제공.
- SHAP 기반 계좌별 근거 상위 3요인 자동 문장화.
- 부담당자 업무량/회수실적 피드백을 정원(150/200)에 반영하는 동적 배분.
- 세그먼트 EB를 계층적 베이즈로 확장(팀→부담당자→차주 부분풀링).
