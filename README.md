# 코로나채권 AI추천 데스크톱 파이프라인

채무조정이 폐지된 **코로나채권** 중, 기본 안내를 했을 때 **1개월 내 자발 상환
가능성이 상대적으로 높은 채권**을 **부담당자별**로 추천하는 Windows 데스크톱
프로그램입니다.

> 이 도구는 **법조치/강한 추심 추천 모델이 아닙니다.** 자발 상환 가능성이 높은
> 안내 우선순위를 뽑는 것이 목적이며, 법조치 관련 기능은 포함하지 않습니다.

- 상태(추천 이력·피드백·학습 모델)는 **로컬 SQLite 파일 1개**에 자동 누적됩니다.
- **학습데이터는 최초 1회만** 업로드합니다. 이후에는 활동데이터 + 전월 피드백만
  넣으면 됩니다.
- **실행(추론) 중 외부 네트워크/API 호출이 전혀 없습니다.** 외부 통계는 사전
  수집된 정적 상수로 코드에 내장되어 있습니다.

## 1. 폴더 구조

```
repo/
  run_app.py            # exe 진입 스크립트(PyInstaller 엔트리)
  requirements.txt
  build.bat             # 외부망 노트북 원클릭 빌드
  build_offline.bat     # 폐쇄망 오프라인 빌드(wheels 사용)
  corona_reco.spec      # PyInstaller 스펙(CatBoost 등 번들)
  README.md
  corona_reco/          # 파이썬 패키지
    main.py             # tkinter GUI
    config.py           # 상수: 외부prior, 제외리스트, 팀 roster, 가중치, 컷
    io_loader.py        # csv/xlsx 로더(UTF-8/EUC-KR 자동), 컬럼 별칭
    payments.py         # 입금내역 파싱·파생값
    features.py         # ML 피처 빌드 + 누수 blacklist 게이팅
    scoring.py          # base/payment/burden/prior/penalty/collateral + 최종식
    exclusions.py       # 강제 제외 규칙 + 차주단위 전파
    model.py            # CatBoost Hurdle + bagging + 검증(Lift@K) + champion-challenger
    feedback.py         # 피드백 파싱 + EB 세그먼트 캘리브레이션 + 혼합비중
    grading.py          # 차주통합·등급·부담당자 상한/최소보장·팀배정
    store.py            # SQLite 스키마·누적·dedup·모델메타
    report_excel.py     # 실무 보고서(스타일/색상/필터)
    feedback_excel.py   # 피드백 파일(사용자시트 + 숨김시트)
    reasons.py          # 추천사유 문장 생성
    pipeline.py         # 실행 오케스트레이션(최초/월별)
    tests/              # pytest: 반례 + 누수게이팅 + 합성 e2e
```

## 2. 운영 순서

### 2-1. 최초 실행 (딱 한 번)
1. 프로그램(`코로나채권AI추천.exe`)을 실행합니다.
2. **실행 모드 = "최초 실행"** 선택.
3. **활동데이터**(이번 달 관리 채권)와 **학습데이터**(입금내역이 오른쪽에 붙은 파일)를
   각각 선택합니다.
4. **평가 기준일**(최근성 판정 기준일)과 **추천월**(예: `2026-07`)을 확인합니다.
   - ⚠️ 최근 입금 판정은 시스템 날짜가 아니라 **평가 기준일** 기준입니다.
5. **실행**을 누릅니다. 완료되면 `data/` 폴더에 다음이 생성됩니다.
   - `추천보고서_YYYY-MM.xlsx` (실무용)
   - `피드백_YYYY-MM.xlsx` (다음 달 재업로드용)
   - `corona_reco.sqlite`, `catboost_hurdle.joblib`, `train_snapshot.joblib`

### 2-2. 월별 실행 (매월)
1. **실행 모드 = "월별 실행"** 선택.
2. 이번 달 **활동데이터**와, 지난달에 받았던 **피드백 파일(값을 채운 것)**을 선택합니다.
   - 피드백 파일의 **실제입금여부/실제입금액/입금일자**를 채워서 올리면 됩니다.
   - 학습데이터는 **다시 올리지 않습니다.**
3. **실행**을 누르면 피드백이 DB에 누적되고, 성과 보정(EB 캘리브레이션)과 필요 시
   증분 학습(champion-challenger)이 반영된 이번 달 보고서 + 다음 달 피드백 파일이
   생성됩니다.

---

## 3. 입력 파일

- **활동데이터**: 월별 관리 채권 목록(순번, 고객번호, 대출번호, 성명, 주민등록번호,
  부담당자, 채권상태, 회생, 현재원금, 채권구분, 차주구분 등).
- **학습데이터(최초 1회)**: 활동데이터와 동일 구조 + 오른쪽에 입금내역이 가로형으로
  반복(`입금일자1, 입금액1, 입금일자2, 입금액2, ...`). 헤더가 없으면 CC~CV 위치로
  자동 인식합니다.
- **피드백 파일(월별)**: 지난달 생성된 `피드백_*.xlsx`에 실제 성과를 채운 것.
  컬럼명이 달라도(`입금액`/`납입금액`/`실제입금액`, `입금여부`/`실제입금여부` 등)
  자동 인식합니다.

CSV는 UTF-8/EUC-KR(CP949)을 자동 판별합니다. 엑셀 파일도 지원합니다.

## 4. 데이터 파일 위치 & 백업

- 모든 상태 파일은 **exe 옆 `data/` 폴더**(또는 GUI에서 지정한 폴더)에 저장됩니다.
  - `corona_reco.sqlite` — 추천 이력·피드백·모델메타·세그먼트 통계
  - `catboost_hurdle.joblib` — 학습된 모델
  - `train_snapshot.joblib` — 증분 학습용 원본 학습 스냅샷
- **백업**: 월 1회 `data/` 폴더 전체(특히 `corona_reco.sqlite`)를 복사해 두세요.
  파일을 잃어버리면 누적 이력과 학습 결과가 사라집니다.
- 이 파일들을 수동으로 들고 다닐 필요는 없습니다. 같은 PC에서 계속 누적됩니다.

## 5. 개인정보(주민등록번호) 처리

- 주민등록번호 **원본은 어떤 산출물/DB/엑셀에도 저장·출력되지 않습니다.**
- 앞자리로 **나이대·성별만** 계산한 뒤 원본은 즉시 폐기합니다.
- **성별은 점수에 반영하지 않으며**, 공정성 진단(추천률/입금포착률 표시)에만 쓰입니다.
- 나이대는 약한 보조 prior(±3점 이내)로만 쓰이며 단독으로 등급을 뒤집지 않습니다.

## 6. 점수 · 등급 요약

- 최종점수 = (가중합 × 담보부NPL 배수) − 민감패널티 + 외부prior보정 + 피드백보정
  (+ Stage2보정, 활성 시), 0~100 clamp.
  - 기본 가중치: base 0.30 / paid_similarity 0.35 / payment_history 0.20 / burden 0.15
    (GUI에서 조정 가능, 합은 자동 정규화)
  - **Stage2(예상회수)**: 기본 OFF. GUI에서 켜고 표본이 충분하면 회수비율 회귀가
    학습되어 `예상회수` 값이 `상세진단(개발용)` 시트에 표시되고 점수에 소폭(+최대 3점)
    반영됩니다. OFF일 때는 최종식이 위 기본형과 동일합니다.
- 차주(고객번호+성명) 통합점수 = 0.70×max + 0.30×mean − 다중계좌부담패널티.
- 등급 절대컷(기본): S≥70 / A≥55 / B≥40 / C≥25 / 미만 D. 담보부NPL 등급상한 적용.
- 부담당자별 상한: S 최대 20명, A 최대 100명. 추천리스트 **최소 20명 보장**(부족 시 전원).

### 강제 제외(안내 금지) 규칙 — 사유는 반드시 기록
1. 원장상태 ≠ 활동
2. 채권상태(중) ∈ {사망, 완제, 면책, 시효, 말소}
3. 채무부존재소송 있음
4. 회생 ∈ {신용회복동의회신, 인가결정, 개시결정, 신용회복지원확정, 신용회복지원신청, 면책허가}
5. (기본 ON) 시효일자가 평가 기준일 이전(소멸시효 완성)

- `폐지_신복/폐지_회생/폐지_파산`은 **안내 가능**(제외하지 않음).
- `부채증명원`은 **무시**(패널티·플래그 없음, 정상 컨택).
- **차주 단위 전파**: 연락금지(회생)·사망·면책은 동일 차주의 모든 계좌를 제외합니다.

## 7. 빌드 방법 (.exe 생성)

### 외부망 노트북(권장)
```bat
build.bat
```
`venv` 생성 → 의존성 설치 → **pytest(누수 게이팅 포함, 실패 시 중단)** → PyInstaller
단일 exe 빌드 → `dist\코로나채권AI추천.exe` 산출.

### 폐쇄망(오프라인) 재빌드
1. 외부망 노트북에서 휠을 미리 받아둡니다.
   ```bat
   pip download -r requirements.txt -d wheels
   ```
2. `wheels/` 폴더를 폐쇄망으로 옮긴 뒤:
   ```bat
   build_offline.bat
   ```
> 완성된 exe 자체는 **실행 중 네트워크가 전혀 필요 없습니다.** 오프라인 절차는
> "재빌드"가 필요한 경우에만 씁니다.

```bat
python -m pytest corona_reco\tests -q
```
HTML판에서 확정된 반례(폐지 안내 가능, 회생 강제제외, 사망/완제 제외, 민원 −25 1회,
담보부NPL 배수/상한, 개인사업자 보정, 주민번호 처리, 시효 제외, 부채증명원 무시,
차주단위 전파, 팀 roster 우선, 피드백 별칭)와 **ML 누수 게이팅**, **합성 데이터
end-to-end**(학습→추천→엑셀2종→DB누적→피드백주입→재추천)를 검증합니다.
누수 게이팅이 실패하면 빌드가 중단됩니다.

## 9. 출력물

- **추천 보고서**(`추천보고서_*.xlsx`): `전체/1팀/2팀 추천리스트`, `피드백 작성 안내·요약`,
  (옵션) `상세진단(개발용)`. 팀별 리스트는 8개 컬럼만 노출
  (고객번호·이름·원금잔액·다중계좌원금잔액·부담당자·등급·회생·추천사유),
  헤더 고정·필터·금액 콤마·S/A 등급 강조.
- **피드백 파일**(`피드백_*.xlsx`): 사용자 입력 시트(실제입금여부/실제입금액/입금일자/비고는
  빈 칸) + 숨김 시트(추천시점 피처벡터·대출번호·모델버전).
